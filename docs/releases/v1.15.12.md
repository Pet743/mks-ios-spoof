# MKS 1.15.12 / 128

本版发布与 RootHide 真机已测试产物相同的安装包。已验证无双重认证账号在“退出并重开确认未登录 → MKS 正常改机 → 一次密码登录 → 重开保持”流程成功，用户后台核对机型、系统和 IMEI 一致，改机持续启用。

## 更新

- RootHide 改机/恢复前自动刷新认证和商店进程，检查旧 PID 退出，并处理退出中的短暂状态；正常流程无需手工 killall。
- RootHide 新参数采用对应的 iPhone 15 Pro Max / iOS 17.0 / build 21A329 元组，继续生成新的身份标识。
- 修正 IOKit Search 白名单外字段被额外改写的问题，并对照 DPP 静态实现增加原始 MG 初始化读取。
- Rootless 原有参数生成、刷新和 hook 行为保留；本版完成构建与主机检查，未做本轮 Rootless 真机登录验收。

## 安装

使用 Sileo 等越狱包管理器安装一份与环境对应的完整 DEB：

- **RootHide**：`mks_1.15.12_roothide_iphoneos-arm64e.deb`，依赖 RootHide 核心包及该环境的 ElleKit。
- **Rootless**：`mks_1.15.12_rootless_iphoneos-arm64.deb`，依赖 ElleKit。

DEB 包含 MKS App、注入库和后台服务，安装后从桌面的 MKS 打开。巨魔单装独立 IPA 缺少完整插件和后台服务。覆盖升级保留原有配置、状态与备份，不自动生成新参数。

# MKS 1.16.0 / 132（预发布）

增加“自定义 iOS 版本”入口，只需选择 iOS 16、17 或 18。小版本与 build 从离线固件对应表配套选择，其他参数自动生成；生成结果在保存前执行本地参数规则校验。

- “保存大版本供后续改机使用”保存偏好，App 一键改机和 HTTP `/spoof` 共用该设置。
- “应用”保存当前预览并刷新；预览本身不修改当前生效参数。
- 错误或损坏的偏好会停止生成，不覆盖现有配置；还原原机继续可用。
- 保留 1.15.14 的 USB 配对修复、版本显示和既有服务处理。本版未修改购买服务的身份读取策略。

## 已知问题

**改机状态下的应用内购问题尚未解决。** 用户报告同一台 RootHide 设备还原后可购买、启用改机后失败。已观察到“购买未完成，向 Apple 支援提交申请以供审核”的提示；该提示不说明具体字段或代码根因。当前未通过内购验收，因此作为预发布提供，稳定发布仍为 1.15.14。这里的“稳定发布”表示既有发布分类，不表示已验证其内购正常。

本地 HTML 校验验证格式和部分字段关系，不等同于 Apple 账号认证、交易审核或购买成功。原参考 HTML 的批量“认证通过”显示存在未逐条执行校验的问题，MKS 的生成结果使用实际校验函数验证。

## 验证

Rootless、RootHide 各通过 3659 项大版本生成和偏好检查；两种环境共 606 个正负样例与参考 HTML 的实际 `verify()` 函数交叉检查通过。此前已完成核心、身份读取、USB、服务刷新、HTTP 回归及双架构安装包校验。

模拟器已验证三个大版本切换及保存。RootHide 真机已安装 1.16.0 / 132，服务、版本显示和 USB 配对正常；升级保留原参数及绑定。Rootless 本轮只有构建和主机验证，无真机内购验收。

## 安装包

- `mks_1.16.0_roothide_iphoneos-arm64e.deb`
- `mks_1.16.0_rootless_iphoneos-arm64.deb`
- `SHA256SUMS-1.16.0`

安装包沿用已验证的本地产物，RootHide 包与本次已安装设备的包一致。下载后可执行 `shasum -a 256 -c SHA256SUMS-1.16.0` 核对文件。
